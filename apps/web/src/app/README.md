# Слой `app` — инициализация приложения

Всё, что нужно для запуска: точка сборки, провайдеры, роутинг, глобальные стили, лейауты.

| Папка        | Что лежит                                                  |
| ------------ | ---------------------------------------------------------- |
| `providers/` | React-провайдеры: TanStack Query, будущие Theme/Auth       |
| `routes/`    | `createBrowserRouter`, связывание путей с pages            |
| `layouts/`   | Каркасы страниц (`BaseLayout` = Sidebar + Header + Outlet) |
| `styles/`    | `globals.css`, Tailwind-директивы                          |
| `App.tsx`    | Корневой компонент: провайдеры + RouterProvider            |

**Может импортировать:** все слои ниже. **Никто не импортирует app.**
