# Слой `shared` — переиспользуемая инфраструктура

Ничего не знает о бизнес-логике. Не импортирует никакие слои выше.

| Папка     | Что лежит                                                   |
| --------- | ----------------------------------------------------------- |
| `api/`    | Клиент Supabase, базовые обёртки запросов                   |
| `config/` | Константы маршрутов, env-конфиг                             |
| `lib/`    | Форматтеры (деньги, вес, даты), `cn()` и прочие хелперы     |
| `ui/`     | Базовые UI-примитивы (кнопки, инпуты, модалки) — Спринт 2.1 |
| `types/`  | Общие TS-типы фронтенда                                     |

Доменная логика (формулы цены, статусы, Zod-схемы) — НЕ здесь,
а в монорепо-пакете `@prient-flow/shared`.
