# Слой `entities` — бизнес-сущности

Одна папка = одна сущность БД. Здесь живут типы, API-запросы к Supabase
(TanStack Query hooks), мелкие UI-карточки сущности.

Планируемые слайсы (по схеме БД из ROADMAP Этапа 1):

- `entities/order/` — заказы и позиции (`order_items`)
- `entities/material/` — склад расходников
- `entities/printer/` — парк принтеров и их статусы
- `entities/client/` — клиенты мастерской
- `entities/workspace/` — текущая мастерская и её настройки

Стандартные сегменты слайса:
`api/` (запросы), `model/` (типы, стор), `ui/` (карточки/бейджи), `lib/` (хелперы сущности), `index.ts` (public API).

**Импортирует:** только shared.
