# Команда: /формат (для PrintFlow ERP)

Когда пользователь вводит команду `/формат`, выполни в корне монорепозитория
полный цикл проверки качества кода:

## Шаг 1 — Автофикс форматирования

```bash
pnpm format:fix
```

Prettier перезапишет файлы в каноничном виде (`.prettierrc.json`).

## Шаг 2 — Автофикс линтера

```bash
pnpm lint:fix
```

ESLint исправит то, что чинится автоматически.

## Шаг 3 — Проверка типов

```bash
pnpm typecheck
```

`tsc --noEmit` по `packages/*/src` и `apps/*/src` (корневой tsconfig.json).
Ошибки типов автофиксом не лечатся — исправь код руками.

## Шаг 4 — Финальный отчёт

Выведи пользователю сводку:

- ✅/❌ Prettier — сколько файлов переформатировано
- ✅/❌ ESLint — сколько проблем осталось после фикса (файл:строка — причина)
- ✅/❌ TypeScript — список ошибок типов, если есть
- Общий вердикт: готов ли код к коммиту

## Правила

- Запускай команды именно в этом порядке: format → lint → typecheck.
- Если после автофикса остались ошибки линтера или типов — исправь их в коде,
  затем повтори полный цикл, пока всё не станет зелёным.
- Не коммить без явной команды пользователя; только доложи статус.
- Эквивалент ручной полной проверки без фикса: `pnpm ci:check`
  (lint + typecheck + format --check).
