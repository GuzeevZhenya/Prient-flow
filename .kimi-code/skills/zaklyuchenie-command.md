# Команда: /заключение (для PrintFlow ERP)

Когда пользователь вводит команду `/заключение`, проанализируй текущую сессию
и создай файл отчёта в папке `.docs/history/` с именем
`YYYY-MM-DD_printflow-summary.md` по следующему шаблону:

```markdown
# Итоги сессии: PrintFlow ERP — [Краткая тема]

## 📌 Что было сделано

- [ ] Разработанные модули, сущности ERP или доработки интерфейса.
- [ ] Исправления в бизнес-логике расчётов / статусов заказов.

## 📂 Затронутые пакеты и файлы (Monorepo)

- apps/... или packages/... — что именно было добавлено или изменено.

## 🗄️ База данных и контракты

- Изменения в миграциях Supabase, схемах Prisma/Zod, типах TypeScript или API-клиентах.

## 🧠 Архитектурные решения

- Принятые решения по структуре монорепо, состоянию или интеграции с Telegram-ботом.

## 🚀 Следующие шаги

- Задачи на следующий сеанс разработки, нерешённые проблемы или технический долг.
```

После создания файла выведи пользователю подтверждение и путь к нему.
